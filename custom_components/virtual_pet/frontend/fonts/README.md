# Fonts

`Tiny5.woff2` is a **modified** copy of Tiny5 (SIL OFL 1.1, see `OFL.txt`; the
font has no Reserved Font Name, so the file name is kept).

Change (Claude, for hatch-at-home, 2026-10-30): the capital `P` glyph now has
a squared bowl (its right wall joins the top and middle bars along an edge).
Upstream draws the wall as a single pixel touching the bars only at its
corners, which made "Pip" read as "Fip" at small sizes and fractional pixel
ratios. Every other glyph is unchanged.
